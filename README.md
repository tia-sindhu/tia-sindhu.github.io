# Tia Sindhu — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. No build tools required.

## Publish on GitHub Pages

Your repository `tia-sindhu/tia-sindhu.github.io` and GitHub Pages deployment already exist.

1. Open `https://github.com/tia-sindhu/tia-sindhu.github.io` and choose **Add file → Upload files**.
2. From the unzipped `tia-portfolio` folder, upload `index.html`, `styles.css`, `script.js`, and the `projects` folder directly to the repository root. GitHub will ask to replace the existing `index.html`; confirm the replacement. Keep your existing notebooks, PDFs, and images.
3. Choose **Commit changes** on the `main` branch. The portfolio will publish at `https://tia-sindhu.github.io/` after GitHub Pages rebuilds.

Note: This new homepage replaces the current `index.html`. Existing `about.html` remains in the repository but the new navigation uses the About section on the homepage.

## Customize

- Edit project descriptions and bio in `index.html`.
- Replace the GitHub profile link in the Contact section if your username differs from `tia-sindhu`.
- The AI recruiting paper, mosaic notebook, both mini data science projects, and the personal loan reference notebook have readable HTML previews and downloadable notebooks linked from their project cards. The personal loan notebook retains its original authorship credit. The Movie Reviews Database card includes its ER diagram and project report. Other projects remain descriptions until you add their original files or repository links.
- Fonts load from Google Fonts; the layout falls back to system fonts when offline.

The Image Mosaic project card shows the final image and links to the full-resolution result, notebook preview, and downloadable notebook.

The About section links the AWS Certified AI Practitioner credential to its verified Credly badge.
